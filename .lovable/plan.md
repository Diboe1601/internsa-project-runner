# Mobile dashboard navigation dock

## Goal
Present student/graduate and admin mobile navigation as one horizontal, compact floating dock with a smooth iOS-inspired appearance.

## Changes
- Preserve current dashboard destinations, mobile Profile shortcut, logout actions, and desktop sidebars.
- Replace the mobile navigation grid with a single-row, horizontally scrollable dock so options never stack or overflow narrow screens.
- Use semantic theme colors, safe-area spacing, floating rounded surface, and restrained motion with reduced-motion support.

## Validation
- Check student and admin docks at phone widths, confirm every destination stays in one row and remains reachable, and verify desktop navigation is unchanged.
- Review preview build status and existing tests.
